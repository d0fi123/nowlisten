# nowlisten

[English](#english) | [Русский](#русский)

---

## English

A lightweight utility for **Google Pixel** users and **Android 16+**, displaying your currently playing music or background video right in the status bar. It leverages the **MetricStyle** notification template to create a clean chip in the Pixel Launcher (AOSP) status bar.

* **Roadmap:** Support for other UI skins is planned for the future.

---

## Русский

Небольшая утилита для пользователей **Google Pixel** и **Android 16+**, которая отображает воспроизводимую музыку или фоновое видео прямо в строке состояния. Она использует шаблон уведомлений **MetricStyle** для создания аккуратного чипса в строке состояния Pixel Launcher (AOSP).

* **Родмап:** В будущем планируется добавление поддержки других графических оболочек.
